02 / QUICK START

처음이라면, 이 순서대로

ZIP 안의 Manual에서 사용법을 확인하세요.

  1. 게임을 창모드로 실행

    NAVYFIELD를 먼저 창모드로 켜세요. 원본 게임 화면 전체가 작업표시줄을 제외한 한 모니터의 작업 영역 안에 들어가야 합니다.

  2. NF resize 실행

    ZIP 압축을 풀고 NF resize 1.6.exe를 실행하세요. 관리자 권한 확인 창이 나오면 허용하세요.

  3. 배율과 화면 비율 선택

    배율 버튼이나 Fit을 누르세요. 직접 지정하려면 숫자 칸에 배율을 입력한 뒤 Enter 또는 Apply를 누르세요. 비율의 기본값은 4:3입니다.

  4. 게임 화면을 클릭해 조작 시작

    화면을 클릭하면 마우스 이동 범위가 게임 영역으로 제한됩니다. 전체화면은 Alt+Enter 또는 Full screen 버튼으로 전환하세요.

  5. 다른 앱으로 이동하거나 종료

    Alt+Tab으로 다른 앱에 이동하세요. 창모드로 돌아오면 화면을 다시 클릭해 조작을 재개하세요. NF resize를 종료하면 원본 게임 창이 복구됩니다.

04 / FAQ

사용 전에 확인하세요

16:9나 21:9를 고르면 게임 시야가 넓어지나요?

아니요. 원본 화면을 선택한 비율로 표시하므로 화면 모양이 달라집니다. 게임의 해상도나 시야를 늘리는 기능은 아닙니다. 원래 비율을 유지하려면 기본값인 4:3을 사용하세요.

게임 화면 밖으로 마우스를 이동하려면 어떻게 하나요?

Alt+Tab으로 다른 앱에 이동하면 제한이 해제됩니다. 창모드로 돌아오면 마우스가 해제된 상태를 유지하므로 게임 화면을 클릭해 조작을 재개하세요.

화질 필터나 선명도 설정도 있나요?

1.6에는 별도의 화질 필터나 선명도 옵션이 없습니다. 화면 확대와 비율 변경 기능을 제공합니다.

종료하면 원래 게임 창으로 돌아가나요?

NF resize를 종료하면 원본 게임 창의 설정과 위치가 복구됩니다.

원본 게임 화면의 크기에 제한이 있나요?

원본 게임 화면 전체가 작업표시줄을 제외한 한 모니터의 작업 영역 안에 들어가야 합니다. 화면이 너무 크면 조작을 시작하지 않고 오류를 표시합니다. 축소 배율에서는 실제 마우스 제한 범위가 화면에 표시된 영역보다 클 수 있습니다.

어떤 환경에서 확인되었나요?

Windows 11 x64 시험 창을 이용한 기능 검사 및 실제 NAVYFIELD 클라이언트 수동 테스트.
